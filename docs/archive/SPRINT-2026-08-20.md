## Process lessons (recorded to memory)

- Merge gates must be scoped to the merge's true blast surface or run full — the two leaks came from "scoped tests + statics" merges whose changes altered generated-catalog counts and example goldens outside the scoped suites.
- Verify by exit code, never through a piped grep — a `| grep` chain swallowed a red suite twice.
- `refs/stash` is shared across git worktrees: concurrent stash use in parallel lanes swapped uncommitted state between two worktrees (recovered byte-identical). Worktree lanes must not use `git stash`.
- Fork CI's first real value arrived immediately: it caught a pre-mount scope-leak regression (#33) and the stale-golden class the same night it was wired.
